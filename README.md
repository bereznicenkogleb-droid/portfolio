# Сайт-портфолио

Готовый сайт для продажи услуг веб-разработки: главная с услугами и ценами,
два кейса, процесс работы, FAQ и контакты. Плюс внутри — живой демо-лендинг
барбершопа, который можно показывать локальному бизнесу.

Чистый HTML + CSS + JS. Без сборки, без зависимостей, без конструкторов.

## Структура

```
site/
├── index.html              портфолио (главная)
├── css/style.css           стили портфолио
├── js/main.js              меню, анимации, копирование почты
├── assets/
│   ├── case-typing.jpg     скриншот теста печати
│   └── case-barber.jpg     скриншот барбершопа
├── barbershop/             демо-лендинг барбершопа (ТОПОР)
│   ├── index.html
│   ├── css/style.css
│   ├── js/main.js
│   ├── assets/             три фото
│   └── README.md           описание демо и кредиты фото
└── README.md
```

Портфолио открывается по адресу `/`, барбершоп — по `/barbershop/`.
Ссылки между страницами относительные, поэтому всё работает и локально,
и на GitHub Pages.

## Как открыть локально

Двойной клик по `index.html`. Всё работает, кроме ссылки на барбершоп
(`barbershop/`) — браузеры не всегда открывают относительные папки с диска.
Если нужно проверить связку: запустите в этой папке любой локальный сервер,
например:

```
python -m http.server 8000
```

и откройте `http://localhost:8000/`.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий, например `portfolio`:
   https://github.com/new → имя `portfolio` → **Public** → **Create repository**.
2. На странице репозитория: **Add file → Upload files**.
3. Откройте папку `site` в проводнике, выделите **всё содержимое**
   (`index.html`, `css`, `js`, `assets`, `barbershop`) и перетащите в браузер.
4. **Commit changes**.
5. **Settings → Pages** → Source: **Deploy from a branch** →
   Branch: `main`, папка `/ (root)` → **Save**.
6. Через 1–2 минуты сайт откроется по адресу
   `https://<ваш-ник>.github.io/portfolio/`.

Важно: перетаскивать нужно **содержимое** папки `site`, а не саму папку,
иначе сайт окажется по адресу `/portfolio/site/`.

## Что продавать с этим сайтом

1. **Демо барбершопа** — главный аргумент для локального бизнеса. Показываете
   на телефоне: «вот так может выглядеть ваш сайт, тут уже есть запись».
2. **Typing Speed Test** — доказательство, что умеете писать код, а не
   собирать шаблоны.
3. **Цены на сайте** — отсекают тех, кто ищет «сайт за 3 тысячи».

Подробный план заработка, шаблоны сообщений и цены — в файле
`MONEY_PLAN.md` в корне проекта.

## Технические детали

- **Шрифты** — системные (Georgia + системный гротеск). Ничего не грузится
  извне: сайт работает офлайн и не зависит от Google Fonts.
- **Анимации** — `IntersectionObserver`, отключаются при
  `prefers-reduced-motion`.
- **Адаптив** — проверено на 390, 768, 897, 1440 px.
- **Скриншоты кейсов** — `assets/case-*.jpg`, сняты с живых страниц.
  При обновлении сайтов скриншоты стоит переснять.
