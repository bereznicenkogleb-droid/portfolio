# Сайт-портфолио

Готовый сайт для продажи услуг веб-разработки: главная с услугами и ценами,
три кейса, процесс работы, FAQ и контакты. Кейсы ведут на отдельные живые
сайты: тест печати, демо-лендинг барбершопа и демо салона красоты.

Чистый HTML + CSS + JS. Без сборки, без зависимостей, без конструкторов.

## Структура

```
site/
├── index.html              портфолио (главная)
├── css/style.css           стили портфолио
├── js/main.js              меню, анимации, копирование почты
├── assets/
│   ├── case-typing.jpg     скриншот теста печати
│   ├── case-barber.jpg     скриншот барбершопа
│   └── case-salon.jpg      скриншот салона красоты
└── README.md
```

Ссылки на кейсы ведут на отдельные сайты:

- Тест печати — https://bereznicenkogleb-droid.github.io/typing-test/
- Барбершоп — https://bereznicenkogleb-droid.github.io/barbershop-demo/
- Салон красоты — https://bereznicenkogleb-droid.github.io/salon-demo/

Каждый проект живёт в своём репозитории и собирается на GitHub Pages
независимо. Портфолио — это витрина, а не папка со всеми работами.

## Как открыть локально

Двойной клик по `index.html` — портфолио откроется. Кейсы ведут на живые
версии в интернете, поэтому локальный сервер не нужен.

## Как опубликовать на GitHub Pages

Репозиторий `portfolio` уже создан:
https://github.com/bereznicenkogleb-droid/portfolio

Если понадобится перезалить вручную:

1. Открыть https://github.com/bereznicenkogleb-droid/portfolio
2. **Add file → Upload files**
3. Выделить **всё содержимое** папки `site` (`index.html`, `css`, `js`, `assets`)
   и перетащить в браузер.
4. **Commit changes**.

Важно: перетаскивать нужно **содержимое** папки `site`, а не саму папку,
иначе сайт окажется по адресу `/portfolio/site/`.

Pages включается один раз: **Settings → Pages** → Source:
**Deploy from a branch** → Branch `main`, папка `/ (root)` → **Save**.

## Что продавать с этим сайтом

1. **Демо барбершопа и салона** — главный аргумент для локального бизнеса. Показываете
   на телефоне: «вот так может выглядеть ваш сайт, тут уже есть запись».
2. **Typing Speed Test** — доказательство, что умеете писать код, а не
   собирать шаблоны.
3. **Цены на сайте** — отсекают тех, кто ищет «сайт за 3 тысячи».

Подробный план заработка, шаблоны сообщений и цены — в файле
`MONEY_PLAN.md` в корне проекта.

## Технические детали

- **Шрифты** — системные (Georgia + системный гротеск). Ничего не грузится
  извне: сайт работает офлайн и не зависит от Google Fonts.
- **Анимации** — `IntersectionObserver`, отключаются при
  `prefers-reduced-motion`.
- **Адаптив** — проверено на 390, 768, 897, 1440 px.
- **Скриншоты кейсов** — `assets/case-*.jpg`, сняты с живых страниц.
  При обновлении сайтов скриншоты стоит переснять.
