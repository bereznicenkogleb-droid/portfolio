# ТОПОР — демо-лендинг барбершопа

Одностраничный сайт для барбершопа: тёмная премиальная тема, золото, крупная типографика.
Чистый HTML + CSS + JS, без сборки и зависимостей. Открывается двойным кликом по `index.html`.

> **Это демо, а не сайт реального бизнеса.** Название, имена мастеров, отзывы, адрес,
> телефон и цены — вымышленные. Перед продажей владельцу нужно заменить данные
> на настоящие (список ниже).

## Что внутри

```
barbershop/
├── index.html          разметка всех секций
├── css/style.css       тема, сетки, адаптив
├── js/main.js          меню, липкая шапка, анимации, маска, форма
├── assets/
│   ├── hero.jpg        фото для первого экрана
│   ├── cut.jpg         стрижка ножницами
│   └── beard.jpg       стрижка + борода
└── README.md
```

## Секции

1. **Первый экран** — заголовок, две кнопки, часы работы / адрес / запись.
2. **Бегущая строка** — список услуг.
3. **Услуги** — прайс без «от» и звёздочек.
4. **Работы** — галерея из двух фото + цитата мастера.
5. **Мастера** — три карточки.
6. **Отзывы** — три отзыва.
7. **Запись** — форма: имя, телефон, услуга, дата, время.
8. **Контакты** — адрес, часы, ссылки, стилизованная карта.
9. **Подвал**.

## Как работает форма

Бэкенда нет, поэтому заявка не уходит на сервер. При отправке скрипт:

1. проверяет имя (от 2 символов), телефон (11 цифр), услугу, дату и время;
2. собирает текст заявки;
3. открывает Telegram с готовым сообщением:
   `https://t.me/topor_barber?text=...`.

Владельцу остаётся нажать «Отправить» в чате. Это бесплатно и не требует сервера.

**Альтернативы для реального проекта:**

- **Форма на почту** — [Formspree](https://formspree.io) или [Web3Forms](https://web3forms.com): 5 минут, бесплатный тариф.
- **Заявки в Telegram-бота** — через бота и `fetch` на serverless-функцию.
- **Онлайн-запись** — [Yclients](https://www.yclients.com) (у них есть виджет, который встраивается в такой лендинг).

## Как менять цвета

Всё в `css/style.css`, блок `:root`:

```css
--bg: #0b0b0c;        /* фон */
--text: #f3f0e9;      /* основной текст */
--gold: #c9a227;      /* акцент */
--muted: #a4a099;     /* второстепенный текст */
```

Меняете `--gold` — перекрашивается всё: кнопки, цифры, линии, иконки.

## Адаптив

- **≥ 1024px** — полная сетка, телефон в шапке.
- **900–1024px** — телефон прячется, отступы меньше.
- **≤ 900px** — бургер-меню, все сетки в одну колонку, фото уходит под текст.
- **≤ 560px** — кнопки на всю ширину, форма в одну колонку.

Проверено в Chrome: 1440, 1024, 768, 390 px.
